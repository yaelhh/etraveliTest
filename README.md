# ✈️ Smoke Test Automation Project

This project automates the smoke testing of flight filters using Java, Maven, and Playwright.

---

## 🧪 Smoke Test Setup

### ✅ Prerequisites

- **Java 17.0.15** installed  
- **Maven 3.9.9** installed  
- **Node.js & npm** installed (required to install Playwright)

---

### 📥 Cloning the Project

Clone the repository using the following command:

```git clone https://github.com/yaelhh/etraveliTest.git```

```cd etraveliTest```

---

### 📦 **Installing Playwright**

From the root of the project, run:

```npm install playwright```

---

### 🚀 **Running the Test**

Once all dependencies are installed, run:

```mvn test```

This command will automatically launch a browser.

When the smoke test finishes, the result should resemble the output shown in the screenshot below.
